# shef.currency change log

## 2.0.0 — 2026-09-29

Модуль приведён к канону [shef.options](https://github.com/bx-shef/options):
сборка, тесты, CI, Composer, документация в репозитории. Мажорная версия —
из-за несовместимостей с 1.x.

**Несовместимо с 1.x:**

* пакет Composer — `bxshef/currency`, тип `bitrix-module` (было
  `shef/currency`, `bitrix-d7-module` — модуль уехал бы в
  `bitrix/modules/shef.shef.currency/`); лицензия MIT;
* PHP 8.2; `shef.options` 3.0.0, `shef.problems` 2.0.0, `shef.insync` 2.0.0
  и выше; `shef.uiclear` больше не нужен (в 1.x стоял в зависимостях, не
  используясь);
* ответ НБ РБ разбирается SimpleXML: расширение PHP — `simplexml` вместо
  `xmlreader`, трейт `Xml\ToArray` shef.insync не нужен;
* порог колебания сравнивает курс за единицу валюты, с коэффициентом, с
  действующим на портале — на эту дату, иначе с последним до неё. В 1.x он
  сравнивал только с курсом на ту же дату, и на новый день курс писался
  всегда; заданный порог начнёт отсеивать мелкие колебания впервые;
* кнопка на странице курсов — только с правом «W» на модуль «Валюты» (было
  «R») и с `sessid` в ссылке;
* `Sync\Mode` убран: дату запроса задаёт `Agent::sync(Date)`.

**Исправлено:**

* курсы переписывались GET-запросом без `sessid` — любая ссылка, открытая
  администратором (CSRF), — и пользователем с правом только на просмотр
  курсов;
* сохранённый пустой коэффициент давал 0, и все курсы записывались нулями.
  Порог и коэффициент теперь разбираются строго, испорченное значение —
  умолчание;
* дата курса передавалась в формате `d.m.Y`: на сайте с другим форматом даты
  курс не записывался;
* агент ставился с id пользователя в поле сортировки (аргументы
  `Agents\Entity` — позиционно, мимо сигнатуры);
* агент оставался в `b_agent` после удаления модуля и падал на каждом
  запуске; удаление модуля снимает его и настройки (`savedata = Y` оставляет
  настройки);
* курс валюты без курса на портале: warning на обращении к `null`;
* ошибка записи курса — с текстом ядра (читался пустой `LAST_ERROR`);
* нет курсов на дату (завтра — до их установки банком) — ошибка с причиной,
  а не молчаливый успех; ответ не XML — ошибка, а не пустой список;
* список без контекстной панели на странице курсов — fatal;
* страница настроек падала с `shef.options` 3.x («Unknown named parameter»
  `indexDoc`).

**Добавлено:**

* итог запроса кнопкой — сообщением над списком курсов;
* `Agent::preview(Date)` — что будет записано, без записи;
* разбор ответа и правило записи — в `Main\Rates`, без ядра, с тестами на
  настоящем ответе банка;
* ответ банка разбирается без сети и внешних сущностей (XXE), строка с
  испорченным кодом, масштабом или курсом не пишется.
