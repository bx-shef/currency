# Примеры

Рабочие примеры к модулю. Не куски псевдокода: каждый файл запускается и сам
проверяет, что получилось именно обещанное. Разойдётся обещание с результатом —
пример падает с ненулевым кодом возврата, и это видит CI
(`tests/examples_test.php`).

## Что здесь есть

| пример | цель | где применять |
|---|---|---|
| [rates.php](rates.php) | правило записи целиком: разбор ответа НБ РБ, валюты портала, коэффициент, масштаб, порог — `Main\Rates` | объяснить, почему курс такой; прикинуть порог и коэффициент; свой отчёт о курсах |
| [preview.php](preview.php) | путь агента на сегодня без записи — `Sync\Agent::preview()` | разобрать «курс не тот» или «агент ничего не записал» на живом портале; проверить доступ к services.nbrb.by |

## Как запускать

Два режима, файлы одни и те же.

**Без портала** — ядро, «Валюты» и модули линейки подменяются заглушками из
`tests/stub/`, классы модуля подключаются автозагрузкой из
`tests/stub/autoload.php` по тому же соглашению, что на портале, а сервер НБ
РБ отвечает сохранённым настоящим ответом на 2026-09-29
(`tests/fixtures/`). Так примеры гоняет CI:

```bash
php examples/preview.php
```

**На живом Битриксе** — подключается пролог, модуль берётся
`Loader::includeModule('shef.currency')`, классы находит автозагрузка. То есть
код примера ровно тот, что вы напишете у себя. `preview.php` ходит в НБ РБ
по-настоящему:

```bash
DOCUMENT_ROOT=/var/www/portal php examples/preview.php
```

Режим печатается первой строкой: `Что модуль запишет сегодня [портал]`. Если
там `[заглушки]`, а вы ждали портал — не нашёлся
`<DOCUMENT_ROOT>/bitrix/modules/main/include/prolog_before.php`.

**Курсы на портале примеры не меняют** ни в одном режиме: `preview()` только
читает. Записать — кнопка на странице курсов или агент.

Модуль на портале должен быть **установлен**, а не просто распакован: иначе
пример честно скажет `Модуль shef.currency не установлен` и вернёт 1.

## Как выглядит успешный прогон

```
Что модуль запишет сегодня [заглушки]

— 1. Настройки
  порог, %: 1
  коэффициент: 1

— 2. План на сегодня
  дата 2026-09-29, курсов у банка: 30
  добавить EUR: 3.4418 за 1
  добавить RUB: 3.5891 за 100
  ok   доллар отсеял порог = array (...)
  ok   ядро не звали = array (...)

ГОТОВО: preview
```

Код возврата `0`. Любая строка `FAIL` означает, что код разошёлся с тем, что
обещает пример: это находка, а не шум. Ни одного `Warning`, `Notice` или
`Deprecated` в выводе быть не должно — обвязка превращает их в исключение.
