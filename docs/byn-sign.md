# Знак белорусского рубля

> Последняя сверка: 2026-10-24. С версии 2.1.0.

Знак утверждён Национальным банком (постановление Правления № 25 от 27.01.2026). Кода в Unicode у
него нет — его рисует шрифт НБРБ `nbrb`: текст «BYN» в этом шрифте становится знаком (лигатура).

## Что делает модуль

| где | как показан знак |
|---|---|
| страницы портала: карточки, списки, канбан, отчёты | формат валюты BYN `# <span class="nbrb-icon">BYN</span>` + стили со шрифтом на каждой странице |
| там, где Битрикс24 выводит формат текстом или вырезает разметку (выгрузки, письма, уведомления, чаты) | «BYN» — текст внутри обёртки |
| печатные формы (Word, PDF) | шаблоном: сумма без обозначения и картинка знака рядом (`install/docgen/deal-byn.docx`) |

Настройка — «Настройки → Настройки модулей → shef.currency», «Обозначение белорусского рубля»:

* **Знак НБРБ** (по умолчанию) — как выше;
* **Br** — `# Br`, текстом, работает везде;
* **BYN** — `# BYN`, текстом;
* **Не менять** — модуль формат не трогает.

Формат пишется в валюту BYN (`CCurrencyLang`) для каждого активного языка — при установке модуля
и при открытии страницы настроек тем, кто может её менять (то есть сразу после «Сохранить»).
Прежний формат запоминается (`SYS_prev_<язык>`) и возвращается при удалении модуля; если прежнего
не было — остаётся `# BYN` (знак без стилей модуля был бы просто HTML). Формат, поменянный руками
после модуля, удаление не трогает.

Нужна валюта BYN в модуле «Валюты». Нет её при установке — формат запишется, когда она появится
и откроют страницу настроек.

## Печатная форма «Сделка»

`install/docgen/deal-byn.docx` (исходник — `tools/docx-template.py`):

* `{SOURCE.OPPORTUNITY~WZ=Y,NS=Y}` — сумма без обозначения валюты (модификатор `NS=Y`
  генератора документов), справа — картинка знака высотой с прописную букву;
* `{SOURCE.OPPORTUNITY~W=Y}` — сумма прописью;
* `{SOURCE.TITLE}`, `{SOURCE.CLIENT.NAME}`, `{DOCUMENT.DOCUMENT_NUMBER}`, дата документа.

Загрузить: CRM → сделка → «Документ» → «Добавить шаблон» (или REST
`crm.documentgenerator.template.add`, `entityTypeId` `2`). Картинка в шаблоне — обычная, не
плейсхолдер: генератор оставляет её как есть, поэтому знак виден в DOCX и в PDF.

Почему не шрифтом: у получателя без установленного шрифта НБРБ символ будет пустым квадратом;
внедрение шрифта в DOCX Word делает только руками («Файл → Параметры → Сохранение → Внедрять
шрифты»).

## Что не проверено

На портале и стенде не проверено (bx-shef/currency — issue проверки): где Битрикс24 выводит формат
валюты без HTML (JS-форматирование `BX.Currency`, канбан, мобильное приложение, «Принять оплату»,
счета), как генератор документов пишет сумму прописью для BYN.
