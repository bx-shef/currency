# shef.currency
Для работы с курсами валют НБРБ

* [change log](CHANGELOG.md)

## Установка
* Установить модуль
* **Убедиться в том, что базовая валюта проекта BYN**
* Проверить на странице [валют](/bitrix/admin/currencies.php) значение **Курс по умолчанию** для всех валют
* Настроить параметры модуля на странице настроек модуля
* Запустить агент на странице настроек модуля

> Проблемы синхронизации записываются в [Журнал событий](/bitrix/admin/event_log.php?set_filter=Y&adm_filter_applied=0&find_type=audit_type_id&find_audit_type[]=SH_PROBLEMS_SYNC&find_module_id=shef.currency)
> 
> * Событие: `[SH_PROBLEMS_SYNC] Проблема с синхронизацией`
> * Источник: `shef.currency`
> 
> А так же в файл `/local/sh_log/sh_problems_sync.log`


## Настройки
|                                             Параметр | Значение по умолчанию | Описание                                                                                                                                       |
|-----------------------------------------------------:|:----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| **Менять курс только при колебании<br/>более чем %** | 0                     | При обновлении будет проверяться процент изменения курса.<br/>Если колебание меньше, то курс не изменится                                      |
|                                      **Коэффициент** | 1                     | Коэффициент будет применен при сохранении ставки курса.<br/>С его помощью можно увеличивать значение на своем проекте относительно курса НБ РБ |

> Администратору системы стоит следить за значением  **Курс по умолчанию** страницы [валют](/bitrix/admin/currencies.php)
> или [CRM.Валюты](/crm/configs/currency/)
>
> Как минимум раз в месяц выставлять коректное значение **Курса по умолчанию**




## Программная часть

### [`\Shef\Currency\Sync\Agent`] Агент

Запускается раз в день и устанавливает курсы по НБРБ.

### [`\Shef\Currency\Sync\Api`] API

Запрашивает курсы в НБРБ

### [`\Shef\Currency\Sync\Events`] События
* `Events::onAdminListDisplayHandler`: для построения кнопки **получить курс** на странице [курсов валют](/bitrix/admin/currencies_rates.php)
* `Events::onBeforePrologHandler`: для обработки нажатия кнопки **получить курс** на [курсов валют](/bitrix/admin/currencies_rates.php)
